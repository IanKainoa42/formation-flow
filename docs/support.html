FormationFlow Support

Getting started

FormationFlow lets you plan formation transitions on a virtual court grid. Tap the grid to place athletes, drag to reposition, and add multiple formations to build a full routine with animated transitions.

Tips

  • Add athletes: Use the roster panel to add athletes with labels and roles
  • Place on grid: Tap the court to position athletes in each formation
  • Preview transitions: Use the playback controls to see animated transitions between formations
  • Custom paths: Add waypoints to control how athletes move between positions
  • Timing: Adjust move delays and hold durations for each athlete
