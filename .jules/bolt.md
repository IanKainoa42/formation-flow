## 2024-06-25 - [Flattening nested spatial hash grid loops]
 **Learning:** In high-frequency step loops, nesting multiple for-loops to search neighbor cells in a grid adds redundant closure/iteration overhead and boilerplate code structure, making the distance checks harder to read.
 **Action:** We optimized these searches by replacing nested `for cx` and `for cy` loops with a statically unrolled `searchCells` array combined with `.lazy.compactMap({ grid[$0] }).joined()`. This stream approach, often paired with a `where otherIndex > index` clause, keeps the distance logic flat and runs efficiently without allocating intermediate arrays for grid cells. Additionally, allocating the `grid` dictionary outside the step-loop and clearing it with `grid.removeAll(keepingCapacity: true)` eliminates heavy per-step heap churn.
